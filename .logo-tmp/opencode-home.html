What is OpenCode?

OpenCode is an open source coding agent. Use it in the desktop app, in the terminal, on your phone or from your own code with the SDK. Read the docs.

  • Any model200+ LLM providers through Models.dev, including local models
  • Any deviceA desktop app, a terminal interface, a mobile app and an SDK for your tools
  • Multi-sessionStart multiple agents in parallel on the same project
  • PluginsWrite plugins to hook into events and extend OpenCode with your own logic
  • MCP serversConnect local and remote MCP servers to give agents new tools
  • Custom agentsCreate specialized agents with their own prompts, models and tools
  • Agent skillsTeach agents reusable workflows with SKILL.md files
  • Custom commandsTurn repetitive tasks into slash commands you can run anytime
  • PermissionsChoose which actions run automatically and which need your approval
  • Undo and redoRoll back recent changes to your files and conversation with /undo
